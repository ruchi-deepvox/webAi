🎤 Voice Agent Integration Example

This example shows how to integrate the voice agent into ANY UI using the unified API.

Step 1: Connect to Agent

Click the button to connect to the voice agent:

How to Integrate

Copy this code to your own UI:

JavaScript Example:

// Step 1: Connect to the unified API
const response = await fetch('http://localhost:8000/api/connect', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        room_name: 'my-custom-room',  // optional
        user_id: 'user-123',           // optional
        user_name: 'John Doe'          // optional
    })
});

const data = await response.json();

// Step 2: Import LiveKit client (add to your HTML head)
// <script src="https://cdn.jsdelivr.net/npm/livekit-client/dist/livekit-client.umd.min.js"></script>

// Step 3: Connect to LiveKit
const room = new LivekitClient.Room();
await room.connect(data.url, data.token);

// Step 4: Enable microphone
await room.localParticipant.setMicrophoneEnabled(true);

// Step 5: Listen for agent audio
room.on('trackSubscribed', (track) => {
    if (track.kind === 'audio') {
        const audioElement = track.attach();
        document.body.appendChild(audioElement);
    }
});

// That's it! Now you can talk to the agent.

React Example:

import { Room } from 'livekit-client';
import { useState } from 'react';

function VoiceAgent() {
    const [room, setRoom] = useState(null);

    const connect = async () => {
        // Call unified API
        const res = await fetch('http://localhost:8000/api/connect', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
                user_name: 'React User'
            })
        });
        
        const data = await res.json();
        
        // Connect to LiveKit
        const newRoom = new Room();
        await newRoom.connect(data.url, data.token);
        await newRoom.localParticipant.setMicrophoneEnabled(true);
        
        setRoom(newRoom);
    };

    return (
        <button onClick={connect}>
            Connect to Voice Agent
        </button>
    );
}

Python Example:

import requests

# Connect to voice agent
response = requests.post('http://localhost:8000/api/connect', json={
    'room_name': 'python-room',
    'user_id': 'python-user'
})

data = response.json()
print(f"Token: {data['token']}")
print(f"URL: {data['url']}")
print(f"Room: {data['room']}")

Available API Endpoints

  • POST /api/connect - Main endpoint to connect
  • GET /api/health - Check API health
  • GET /api/config - Get configuration
  • GET /api/rooms - List active rooms
  • GET /api/room/<name>/participants - List participants
  • POST /api/room/<name>/disconnect - Disconnect room
